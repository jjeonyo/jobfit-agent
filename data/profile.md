## 경력

### (주)지엔텔 — IT팀 사원 (2022.10 – 2024.04)

- EV 점검 보고서 자동화 도구: 전기차 충전기 점검 보고서 작성의 사진 첨부·데이터 입력을 자동화. Python(Tkinter GUI, Pandas, Openpyxl, Pillow)으로 폴더만 지정하면 동작하는 파이프라인 구축 — 파일명 정규식 파싱·분류, 사진 규격 일괄 리사이징(584×378), 점검 데이터의 양식 셀 자동 매핑·이미지 삽입, 결과 파일명 생성·폴더 분류까지 자동화. 파일 누락 같은 예외 상황에서도 중단되지 않는 예외 처리 로직 구현. PyInstaller로 실행 파일을 만들어 비개발자 동료도 바로 쓸 수 있게 사내 배포. 결과: 보고서 작성 시간 월 약 200시간 절감, EV인프라사업팀 실사용률 100%, 2023 올해의 우수직원상(G-STAR Award) 수상.
- 사내 네트워크 포트 정리: 스위치 포트가 무작위로 연결돼 특정 포트를 찾으려면 두 명이 필요하고 확인에 약 15분이 걸리던 문제를 정리. 총무팀 도면을 받아 아웃렛 단자를 직접 열어 전산실까지의 연결 번호를 도면에 기록하고 아웃렛 맵 작성. 결과: 포트 확인 시간 15분 → 1분 이내, 1인 작업으로 가능해짐.
- 전사 IT 인프라 운영: 그룹웨어, 더존 ERP, NAS, 엔드포인트 보안 담당. 안랩 TrusGuard 방화벽·SPAMOUT 솔루션 운영, DMZ 내부 네트워크 모니터링·정책 변경 지원, 그룹웨어 사원 테이블·게시판·자료실 관리, ERP 프로젝트 발주·현황·사원 테이블 관리, NAS 권한(프로젝트·팀·개인 단위) 관리, 미허가 소프트웨어 탐지·차단.

### (주)인포보스 — 인턴 (2022.01 – 2022.02)

- 자생식물 이미지 분류 POC: 국내 자생식물 이미지 분류 모델의 사업 가능성을 검증하는 POC. 이미지 약 17만 장을 수집해 노이즈 제거·레이블 정제로 98,000장으로 큐레이션. ImageNet 사전 학습 VGG19 전이학습으로 108종 분류 모델 설계, 입력 규격(224×224) 전처리 파이프라인 구현. 다중 GPU 분산 학습(MirroredStrategy) 도입, 학습률 자동 조절(ReduceLROnPlateau) 설정. 혼동 행렬 히트맵과 예측 성공·실패 사례 시각화 리포트를 자동 저장. 결과: 분류 정확도 0.78 달성.

## 프로젝트

### LG ELLE — 매뉴얼 기반 RAG AI 사용자 지원 서비스 (LG전자 DX School 3기, 6인 팀, 2025.11 – 2026.06)

- 가전제품 에러코드를 음성으로 물으면 AI가 매뉴얼을 근거로 해결책을 안내하는 멀티모달 에이전트 개발 과제. 백엔드 orchestration과 Flutter 클라이언트 화면 흐름 담당. 임베딩 업로드 파이프라인은 팀원과 공동 개발.
- 매뉴얼 표 구조가 검색 청크에서 깨지지 않게, PDF를 페이지 이미지로 변환해 Gemini로 마크다운화(표는 테이블 구조 유지)하는 전처리 방식을 본인 실험으로 검증하고, LangChain 분할기(청크 1,000자, 중첩 100자)로 청크를 나눔.
- 의미 기반 검색과 키워드 검색을 함께 쓰기 위해 하이브리드 검색 가중치(벡터 0.9 + 키워드 0.1)를 설계하고, 검색 쿼리 확장 적용.
- 외부 API 할당량 초과가 곧 서비스 중단으로 이어지지 않게, 지수 백오프 재시도 등 운영 대응 로직 구성.
- 실시간 비전·음성 서버 구축: FastAPI WebSocket + Gemini Live API로 카메라 프레임·음성 입력을 받아 실시간 응답.
- 대화 기반 안내 영상 생성 파이프라인 구축: 최근 대화 맥락 조회 → Gemini로 숏폼 영상 프롬프트 작성 → OpenAI Sora-2로 영상 생성·상태 폴링·다운로드 → Firebase Storage 업로드 → Firestore에 영상 메시지 저장.
- Flutter 앱에서 홈·채팅·라이브·영상 재생 화면을 분리하고 Firestore 상태 변화를 화면 전환으로 연결.
- 결과: DX 우수상 수상 (2025.12). RAG 답변·생성 영상이 앱 화면 흐름에서 실제로 소비되는 end-to-end 서비스 완성.

### NoHome — 공공데이터 아파트 실거래가 검색·추천 서비스 (SSAFY 1학기 관통 프로젝트, 3인 팀, 2026.06)

- 회원·인증 도메인 전담 (백엔드 + 프론트엔드), 설계 문서화 담당.
- JWT를 라이브러리 없이 HmacSHA256으로 직접 구현해 발급·검증을 만들고 HttpOnly 쿠키 + 리프레시 토큰 회전 적용.
- 회원 검색·비밀번호 재설정 기능과 화면 구현, 회원 검색에는 관리자 권한을 분리해 일반 사용자 접근 차단.
- Spring AI + gpt-4o-mini tool calling으로 AI 챗봇 질의 API(POST /api/ai/chat) 연동.
- 공공데이터 API 호출량과 중복 수집을 줄이기 위해, 이미 수집된 구간은 다시 호출하지 않는 coverage 기반 적재 흐름 설계 (팀 구성).
- 공지사항·관심지역 기능을 API와 화면까지 연결하고, 유스케이스 다이어그램으로 팀 기능 범위를 문서화. 기능 단위 브랜치 + PR 리뷰·머지 흐름으로 협업.
- 결과: SSAFY 1학기 프로젝트 경진대회 최우수상 (서울10반 1등, 2026.06.26), AI 관통PJT 과목 96점.

### 근거 기반 문서 작성 멀티에이전트 파이프라인 (개인 프로젝트, 2026.06 – 2026.10)

- LLM이 생성한 문서에 근거 없는 주장이 섞이는 문제를 구조적으로 막기 위해, 문서의 모든 주장이 근거와 대조 검증되는 파이프라인을 개인 프로젝트로 설계·구현.
- 근거 수집 → 작성 → 사실 검증 단계의 서브에이전트와 Python 검증 스크립트 4종으로, 생성된 모든 주장을 근거 원장과 대조하고 근거 없는 문장이 있으면 통과시키지 않는 구조 설계.
- 결과: 에이전트 호출 46회 → 9회로 축소, 회귀 테스트 115개 통과.
