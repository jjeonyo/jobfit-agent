  - Matcher 근거 청크 top_k 조정 (5 → 필요시 8)
- 검증: 실제 공고 3건으로 엔드투엔드 실행, 출력 JSON 스키마 통과

## Day 4–6: Verifier + 평가셋 20건

## Day 7–9: Gap Planner + 리포트

- Done: 부족 요건별 학습 계획 + 자소서 각도 제안이 리포트에 포함
